# Interactive 3D Credit Card UI 💳

A dynamic, interactive credit card payment form featuring a smooth 3D flip animation and real-time data binding. This project is built entirely with vanilla JavaScript and Tailwind CSS, focusing on clean code, responsive design, and seamless user interaction.

## Features

- **3D Flip Animation:** The card smoothly rotates to reveal the CVV section as soon as the user interacts with the CVV input field.
- **Real-Time Data Binding:** Visual updates for card number, holder name, and expiration date appear instantly on the card preview as the user types.
- **Interactive Focus States:** Custom UI highlights on the card preview mirror the currently active input field, improving the overall user experience.
- **Modern Aesthetic:** A sleek, glassmorphism-inspired layout styled with Tailwind CSS utility classes, utilizing custom shadows and gradient overlays.

## Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6+)**

## Getting Started

No build tools or dependencies required.

1. **Clone the repository:**
```bash
git clone https://github.com/FtmDhn/interactive-credit-card-ui.git

```
2. **Setup:** Ensure the project structure remains intact (keep the img/ and js/ folders alongside index.html).

3. **Run:** Simply open index.html in your preferred web browser.
4. **Test:** Start typing in the payment form to watch the 3D card react in real-time!
